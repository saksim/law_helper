# 06 SECURITY_POLICY：安全、权限与合规策略

## 1. 安全目标

律师案件材料涉及个人信息、商业秘密、客户合同、银行流水和诉讼策略。平台必须做到：

- 数据分级。
- 最小权限。
- 模型调用受控。
- 全链路审计。
- 敏感数据默认保护。
- 高风险输出必须复核。

## 2. 数据分级

| 等级 | 示例 | 处理策略 |
|---|---|---|
| L0 | 法条、公开案例、公开政策 | 可进入常规模型和公共检索 |
| L1 | 工商、公开执行、司法拍卖 | 优先授权数据源，保留来源 |
| L2 | 脱敏案件摘要 | 可按策略使用外部模型 |
| L3 | 合同、证据、聊天记录、案件材料 | 国内合规云/私有化优先，强审计 |
| L4 | 身份证、银行流水、商业秘密、重大未公开争议 | 本地/私有化处理，禁止外部模型 |

## 3. 角色权限

| 角色 | 权限 |
|---|---|
| owner | 租户配置、所有案件、数据源、审计 |
| admin | 用户、权限、插件、数据源配置 |
| lawyer | 授权案件、报告复核、线索操作、任务分派 |
| assistant | 上传材料、初步校对、查看分派任务 |
| reviewer | 复核指定报告和线索 |
| auditor | 只读审计和导出记录 |

## 4. 权限规则

- 默认无权访问任何案件，必须显式授权或由负责人分派。
- 助理只能访问被分派案件。
- 敏感材料 L3/L4 需要额外权限。
- 报告导出必须记录操作人、时间、版本、目标格式。
- 删除操作 P0 采用软删除，管理员可审计。

## 5. 模型调用策略

| 数据等级 | 允许模型 |
|---|---|
| L0 | 国内/国外模型均可 |
| L1 | 国内优先，国外仅脱敏或低敏分析 |
| L2 | 脱敏后可按策略选择 |
| L3 | 国内合规云或私有化优先 |
| L4 | 本地或私有化，禁止外部模型 |

模型网关必须记录：

- 调用人。
- 案件 ID。
- 模型供应商。
- 数据等级。
- 输入摘要。
- 输出摘要。
- 成本和耗时。
- 是否命中策略拦截。

## 6. Prompt Injection 防护

案件材料视为不可信输入。必须：

- 系统指令和材料内容分离。
- 禁止模型根据材料内容改变安全策略。
- 工具调用最小权限。
- 外发动作必须人工确认。
- 输出前做敏感信息检查。

## 7. 数据源合规边界

禁止：

- 绕过验证码、登录、风控、付费墙。
- 未经授权抓取商业平台数据。
- 承诺自动查询非公开房产、车辆、银行账户。

必须：

- 优先授权 API。
- 记录授权状态。
- 记录访问频率。
- 数据源失败时告警并允许人工补录。

## 8. 审计要求

必须记录：

- 谁上传材料。
- 谁查看材料。
- 谁发起查询。
- 调用了哪个插件和模型。
- 输出了什么报告。
- 引用了哪些来源。
- 谁复核、修改、驳回。
- 谁导出或分享。

审计日志不可由普通用户删除。

## 9. 敏感信息处理

- 身份证号默认脱敏展示。
- 银行账号默认脱敏展示。
- L4 原文不进入外部模型。
- 导出报告按权限水印。
- 移动端不缓存 L3/L4 原文。
- 通知中不展示完整敏感信息，只展示摘要和深链。

## 10. 安全验收

P0 上线前必须通过：

- 越权访问测试。
- L3/L4 模型策略拦截测试。
- 审计日志完整性测试。
- 数据源授权状态测试。
- 通知敏感信息泄露检查。
- 报告导出水印和记录检查。

## 11. 交接对象

- 给后端：实现权限、审计、模型网关、数据策略。
- 给前端：控制敏感字段展示、导出提醒和权限状态。
- 给 QA：建立安全和合规测试用例。
- 给运维：建立日志保留、密钥管理和告警策略。
