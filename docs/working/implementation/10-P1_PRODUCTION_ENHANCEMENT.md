# 10-P1 生产增强施工文档

## 1. 阶段目标

P1 生产增强版的目标是让一个律师团队在多个执行案件中持续使用平台，而不是只完成一次 P0 演示闭环。

核心结果：

- 多案件并行运行稳定。
- 数据源失败、模型失败、通知失败都有可见告警和恢复路径。
- 线索评分、律师反馈、报告质量能沉淀为质量看板。
- 备份、密钥、审计、部署和回滚达到团队内真实试用要求。

## 2. 目标用户

| 用户 | P1 诉求 |
|---|---|
| 承办律师 | 多案件线索持续更新，减少噪声，快速看到值得处理的事项 |
| 律师助理 | 批量整理材料、复核低置信度内容、维护监控对象 |
| 团队负责人 | 看到案件进度、线索产出、复核质量和系统风险 |
| 交付/运维负责人 | 能定位失败、降级、回滚、恢复数据 |

## 3. 功能范围

### 3.1 必须实现

| 编号 | 功能点 | 说明 | 验收 |
|---|---|---|---|
| P1-10-01 | 多案件持续运行看板 | 汇总案件、线索、监控、报告、任务、失败告警 | 团队负责人能按案件和状态筛选 |
| P1-10-02 | 数据源失败告警升级 | 将连接器失败、重试、人工补录状态集中展示 | 每个失败能看到来源、原因、重试次数、处理人 |
| P1-10-03 | 监控语义 Diff | 不只展示字段变化，还解释变化为什么可能影响执行 | 事件必须包含变化摘要、影响判断、建议动作 |
| P1-10-04 | 噪声反馈闭环 | 律师可标记无效、重复、已处理，并影响后续排序 | 同类提醒的优先级可被反馈下调 |
| P1-10-05 | 质量看板基础 | 展示解析成功率、低置信度比例、线索确认率、报告驳回率 | 指标按时间和案件可过滤 |
| P1-10-06 | 模型效果评估集 | 从律师确认/驳回/修改中生成评估样本 | 每条评估样本保留输入、输出、人工结论和来源 |
| P1-10-07 | 备份与恢复检查 | 数据和文件对象具备备份状态、恢复演练记录 | Runbook 可查看最近备份和恢复演练结果 |
| P1-10-08 | 密钥与配置治理 | 外部 API、通知 webhook、模型配置可轮换、可脱敏展示 | 配置读取、更新、轮换均有审计 |

### 3.2 暂不实现

- 多律所隔离与平台级租户运营。
- 插件市场上架/审批流程。
- 私有知识图谱和业务开拓情报。
- 原生 App。

## 4. 数据影响

新增或扩展实体建议：

| 实体 | 用途 |
|---|---|
| `quality_metrics` | 存储解析、线索、报告、通知、模型效果指标 |
| `feedback_samples` | 存储律师反馈形成的评估样本 |
| `system_alerts` | 聚合数据源、模型、通知、备份、任务失败告警 |
| `backup_checks` | 记录备份和恢复演练结果 |
| `config_rotations` | 记录密钥和外部配置轮换历史 |

## 5. API/BFF 影响

建议新增：

```text
GET  /bff/team/operations-dashboard
GET  /api/system-alerts
POST /api/system-alerts/{alert_id}/resolve
GET  /api/quality/metrics
GET  /api/quality/feedback-samples
POST /api/quality/feedback-samples
GET  /api/backup-checks
POST /api/backup-checks
POST /api/configs/{config_id}/rotate
```

## 6. 插件与安全要求

- 数据源、通知、模型插件失败必须统一写入 `system_alerts`。
- 反馈样本不得泄露 L3/L4 原文到不合规模型。
- 配置类接口只允许管理员访问。
- 所有质量指标只能展示当前团队授权案件范围。

## 7. 施工顺序

1. 建立 `system_alerts` 和质量指标聚合。
2. 增强监控事件为语义 Diff 和噪声反馈。
3. 建立质量看板与反馈样本。
4. 补齐备份恢复和密钥轮换记录。
5. 更新 Runbook 与 QA 验收计划。

## 8. 验收标准

- 同时存在 5 个以上案件时，团队看板能稳定展示重点状态。
- 数据源失败必须 100% 进入告警列表，并支持人工处理闭环。
- 律师反馈后的无效/重复提醒可被追踪，后续排序可解释。
- 质量看板至少包含解析成功率、线索确认率、报告驳回率、通知送达率。
- 备份恢复和密钥轮换操作均可审计。

## 9. 回滚策略

- 质量看板只读化，失败时不影响 P0 案件工作台。
- 语义 Diff 可降级为字段 Diff。
- 反馈样本生成失败时保留原始复核记录。
- 配置轮换失败时保留上一版本配置并标记告警。
