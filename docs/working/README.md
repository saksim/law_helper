## 放入标准

- 已经决定要在本轮处理。
- 有明确产出目标或待确认问题。
- 修改完成后会进入 `latest/` 或形成新的 `releases/` 快照。

## 不放这里

- 纯脑暴和长期方案推演，放入 `discovery/`。
- 已经稳定对外使用的版本，放入 `latest/`。
- 已冻结的发布包，放入 `releases/`。
